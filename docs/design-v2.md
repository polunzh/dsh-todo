# dsh-todo UI 设计 v2 · Iris Precision

在 v1 之上把整站统一到商业产品级视觉语言。产品结构、数据与交互不变，只重做视觉系统。设计方向经用户确认：**A · 精准布局 + 靛蓝/紫（Iris）品牌色**。

## 品牌色

- 单一强调色 Iris：亮色 `#5b57e0`（深 `#4b45cf`），暗色 `#8b85ff`（`#a7a2ff`）。
- Logo 同步为 Iris 渐变（`icon.svg` 与 `Logo` 组件一致）。
- 修订（主题系统上线后）：`icon.svg` 是插件索引/详情页读取的静态图标，固定使用默认主题 Studio Vivid 绿（`#10a37f → #08745a`）；应用内 `Logo` 组件继续跟随用户所选主题。两者形状一致，颜色来源唯一。
- 彩色只用于两处：品牌强调（勾选、进度、主按钮、活动态、番茄环）与优先级语义（P0 红 / P1 红 / P2 琥珀 / P3 蓝 / P4 灰）。

## Token 体系

- **间距**：4 / 8 基准网格。
- **字号阶梯**：10 / 10.5 / 11 / 11.5 / 12 / 12.5 / 13.5 / 15 / 20。
- **圆角**：`--todo-r-sm/md/lg` → 派生自 `--dsw-radius-sm/md/lg`。
- **阴影**：`--todo-shadow-sm/md` → 派生自 `--dsw-shadow-lv1/lv2`。
- **结构色**：背景/字色/边框全部走 `--dsw-alias-*`，随宿主亮暗自动适配。
- **品牌色**：集中在 CSS 末尾 `/* brand-palette:start */ … end */` 区块，是唯一允许字面色值的地方（含宿主侧边栏徽标与 dock 环用的全局 `--dsh-todo-*`）。`client-i18n.test.js` 已改为只对该区块放行，其余仍禁止硬编码色值。

## 组件规则

- **侧栏**：34px 行高，活动项为 Iris 浅底 + 左侧 3px 强调条 + 强调色图标；计数极简；底部专注卡。
- **顶栏**：标题 20px/-0.022em，日期次要色；搜索 34px 卡片；优先级筛选择中才着色；番茄胶囊 34px。
- **任务行**：2px 细优先级指示条 + 右侧 P 标签（P0 实心红标签）；元信息去胶囊化，仅标签保留浅底；勾选 18px 圆环，完成填 Iris。
- **右栏（新增）**：今日概览环 + 本周专注柱与三项 KPI + 接下来清单；< 1180px 收起。
- **快捷添加**：46px 卡片 + Iris 提交按钮 + 聚焦环。
- **番茄钟**：6px 细环，专注 Iris、休息蓝；时间 44px 细体。
- **日历 / 抽屉 / Toast / dock / 侧边栏秒级徽标**：统一圆角、Iris 高亮与语法。

## 响应式与无障碍

- < 1180px 收右栏；< 860px 侧栏折叠为顶部下拉、隐藏统计卡；移动端操作按钮常显。
- focus-visible 统一 2px 环；`prefers-reduced-motion` 关闭动效；对比度沿用宿主 token。

## 与 v1 的差异

无功能变更；新增右侧上下文栏与 Iris 品牌体系，重排间距/字号/组件形态。数据、路由、工具、i18n 键（新增 `rail.*`）与测试均保持兼容。
