# 专注进行中时会话顶栏倒计时：设计

## 问题

当前真实 DSH 会话页在「专注」进行中时，右上角工具占据了容器宽度但未显示可读倒计时；侧边栏仍会显示秒级剩余时间。仓库预览中的同一状态能显示 `18:41`，说明番茄状态、剩余时间计算与预览样式均正常，差异发生在真实会话顶栏插槽的宿主样式环境。

## 目标

专注、短休、长休三个运行状态都在右上角保留可读的 `mm:ss`。倒计时在顶栏空间紧张时优先级最高，任务名、模式名与跳过操作依次收起；暂停/继续始终可用。

高保真目标状态见 [pomodoro-header.png](./design-mockups/pomodoro-header.png)：右上角中的「专注 18:42」即本次专注运行态必须稳定呈现的内容。

## 视觉与交互

- 计时器维持现有 30px 高度、进度环、靛蓝主操作和任务入口，避免形成第二套番茄钟界面。
- `mm:ss` 作为独立的「读数」元素，使用明确的 `inline-flex`、不收缩宽度、表格数字和显式前景色；它不依赖外层按钮或宿主工具条的文字继承。
- 运行中的专注读数使用主文本色；休息继续沿用各自模式色。环形进度仅提供视觉提示，`mm:ss` 是主信息。
- 宽度收缩顺序：任务标题（≤1180px）→ 模式名（≤1040px）→ 跳过按钮（≤920px）。读数与暂停/继续按钮在所有上述宽度中保留。
- 进度环、模式名和任务名所在的主入口打开待办面板；暂停/继续和跳过仍为独立、带名称的按钮。读数保持纯状态展示，避免同一操作出现重复入口。键盘焦点和已有 tooltip 保持。

## 可访问性

- 计时器根节点提供当前模式和剩余时间的动态 `aria-label`；不使用每秒播报的 live region，避免屏幕阅读器持续打断对话。
- 时间文本保留在可访问名称内，控制按钮继续拥有本地化 `aria-label`。
- 亮色与深色主题都使用显式文本 token，确保宿主覆盖或继承规则无法把读数变成透明或同背景色。

## 范围

- `lib/client.js`：将顶部读数从主入口按钮内部拆出为稳定的显式读数元素；为运行态补强选择器与响应式收缩规则。
- `test/client-i18n.test.js`：断言运行态读数结构、计时优先级和顶栏插槽注册。
- `preview/index.html`、`scripts/screenshot.mjs`、`preview/screenshots/header-timer*.png`：以专注运行态为主截图，覆盖亮/暗/紧凑宽度。
- `README.md`、`README.zh-CN.md`：刷新对应顶栏截图和说明，反映已验证的显示行为。

## 验收

1. 专注进行中时，真实 DSH 对话页右上角清晰显示 `mm:ss`，并每秒递减。
2. 短休和长休继续显示其模式与倒计时；暂停、继续、跳过和打开待办面板可用。
3. 宽度收缩时，时间读数与主操作始终保留，且不覆盖宿主右侧控制。
4. 中文、英文、亮色、深色及紧凑宽度截图均能看见读数；完整测试、语法检查、UI 检测与真实 GUI 刷新验证通过。
