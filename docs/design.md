# dsh-todo 设计

## 目标

在 DSH Web GUI 里做一个日常可用的待办 + 番茄钟插件：侧边栏一个入口，主面板是一个完整的 TODO 应用；任务落到本机 JSON，刷新浏览器不丢；智能体也能读写同一份任务。

参考对象：

- **Todoist**（跨平台用户量最大的待办应用）：Today / Upcoming / Inbox / 项目 + P1–P4 优先级 + 自然语言快速添加 + 完成记录。
- **TickTick**（番茄钟与待办结合得最好的主流应用）：任务绑定番茄钟，25/5 循环，长休息，专注统计。

只参考结构与交互，不复制品牌、图标与文案。

## 功能范围（v1）

### 任务

- 字段：标题、备注、截止日期（日期，可选时刻）、优先级 P1–P4、所属项目、标签、完成状态、完成时间、创建时间、顺序。
- 自然语言快速添加：`明天 15:00 写周报 #工作 !p1` → 解析出日期、时刻、项目、优先级；无法解析的部分原样留在标题里。
- 视图：今天、即将到来（按天分组）、收件箱（无日期）、已完成（最近 30 天）、每个项目。
- 操作：完成/撤销、编辑、删除（带撤销）、拖拽排序（v1 用上移/下移按钮，避免与宿主滚动冲突）、搜索、按优先级筛选。
- 快捷入口：每个视图顶部的快速添加框；`Enter` 提交，`Esc` 清空。

### 番茄钟

- 模式：专注 25 分钟 / 短休 5 分钟 / 长休 15 分钟，每 4 个专注后进入长休（时长与间隔可在设置里改）。
- 可绑定一个任务；专注结束后该任务累计 1 个番茄。
- 结束提醒：浏览器通知（有权限时）+ 合成提示音 + 页内提示条；不依赖系统通知权限。
- 状态持久化在 `localStorage`（含 `endsAt` 时间戳），刷新页面继续倒计时，不会每次写宿主。
- 每次完成的专注写入宿主 `sessions`，用于统计：今日番茄数、今日专注分钟、近 7 天柱状图、连续专注天数。
- 面板顶部常驻当前番茄钟状态，任意视图都能看到并暂停/继续。
- 对话页输入框下方注册 `conversation.composer.dock` 常驻计时条：空闲显示当前专注时长，运行中显示倒计时、绑定任务与暂停 / 跳过。用户不打开待办面板也能看到并控制番茄钟。
- 侧边栏图标在番茄钟开始后显示 `分:秒` 倒计时：收起栏贴在图标下方（不遮挡 Logo），展开栏挂到该行右端、落在名称后面；未开始过则完全不显示。宿主行固定为「图标 span + 名称 span」，名称后没有插槽，所以展开态用所在行的右端定位。

### 快捷键

- 通过宿主 `ctx.shortcuts` 注册两个命令：开始 / 暂停番茄钟、打开待办面板。
- 默认组合 `primary+alt`（macOS `⌘⌥`、Windows `Ctrl+Alt`），冲突时依次尝试备选字母；服务缺失时静默跳过，不影响插件其余功能。

### 智能体工具

一个工具 `todo`，`action` 参数区分操作，与 UI 共用宿主存储层：

| action | 参数 | 说明 |
| --- | --- | --- |
| `list` | `view`（today/upcoming/inbox/completed）、`project`、`query` | 返回任务清单 |
| `add` | `title` 必填，`due`、`priority`、`project`、`note`、`labels` | 新建，返回 id |
| `update` | `id` 必填，其余可选 | 改字段 |
| `complete` | `id` | 标记完成 |
| `delete` | `id` | 删除 |
| `stats` | — | 今日番茄与任务完成数 |

工具名与内置的 `todo_write`（会话内计划）区分开：`todo_write` 是模型给自己看的步骤清单，本插件是用户的任务库。

### 界面

- 侧边栏入口：图标 + 「待办」。
- 主面板 `main`，自绘页面骨架：
  - 顶栏：视图标题、日期、今日完成进度、番茄钟胶囊。
  - 左栏：视图导航 + 项目列表 + 今日番茄统计。
  - 右栏：快速添加框 + 任务列表（按日期分组）+ 完成区折叠。
- 跟随宿主主题 token（`--dsw-alias-*`），亮/暗自动适配；窄屏（< 760px）收起左栏为顶部下拉。
- 文案走宿主 `locale` 服务，中/英双字典；宿主 locale 不可用时本地兜底中文。

## 技术方案

```
浏览器 (lib/client.js)                宿主 (lib/index.js)
├─ 侧边栏图标 sidebar.panellist       ├─ /todo/api/* 同源路由
├─ 主面板 main key="dsh-todo"   ────► ├─ lib/store.js  JSON 原子写入
├─ 番茄钟计时 + localStorage           ├─ ctx.tools.register('todo')
└─ 通知 / 音效 / 主题                  └─ 明文错误码 → HTTP 状态
```

- **数据文件**：`$DSH_HOME/storages/todo/state.json`，临时文件 + rename 原子写，损坏文件留档后从空状态开始；同一台机器的 Web 与 Desktop 共用。
- **路由**：`GET /todo/api/state` 一次取全部（任务 + 项目 + 设置 + 统计）；写操作走 `POST /todo/api/tasks/create|update|delete|toggle|move`、`/projects/*`、`/settings`、`/sessions/record`。请求走同源 fetch，`ctx.connection.requestRejection` 做来源校验。
- **不引入依赖**：宿主只用 Node 内置模块，客户端只用宿主注入的 `react`，不 import 任何 `@deepseek-ai/*` 包（profile 安装的 bundle 解析不到它们）。
- **不改宿主状态**：不注册新的 session 事件类型，不写 `cordis.patch.yml`，插件自己的数据只在自己目录里。

## 不做（v1）

账号与多端同步、协作、子任务、重复任务、附件、日历视图、系统级提醒通知（需要原生权限）、AI 自动拆分任务。

## 验证

1. 单元测试（`node --test`）：store 的增删改查、自然语言解析、番茄钟状态机、i18n 键一致。
2. 路由测试：用 `createHandler` 直接打 HTTP，覆盖成功与错误码。
3. 真机验证：安装 bundle → 侧边栏出现「待办」→ 主面板渲染 → 新建/完成/删除任务 → 番茄钟跑完一个 1 分钟自测周期 → 刷新后数据仍在 → 智能体调用 `todo` 工具返回同一份数据。
4. 截图：`preview/` 本地预览页（桩掉 API）导出中英文、亮暗、窄屏截图，用于 README。
