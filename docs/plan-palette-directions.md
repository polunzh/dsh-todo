# Studio Vivid 配色方向实施计划

## 范围

在用户选定一个方向后，才将该方向应用到插件。当前四份高保真稿仅用于评审，不影响运行中的插件。

## 实施步骤

1. 将选定方向的亮暗主题色整理到 `lib/client.js` 的 `brand-palette` 区块，保留集中管理色值的既有约定。
2. 将主色用于活动导航、快速添加、完成选框、进度环和焦点态；继续让 P0–P4 使用现有语义色。
3. 为填充控件设置明确的前景色，验证亮色与暗色的文字对比；信息性文字保持 AA 对比度。
4. 运行现有测试和截图脚本，覆盖今天、日历、番茄钟、会话顶栏、侧栏、中文/英文与亮暗主题。
5. 更新双语 README 截图与界面说明，递增版本，提交并推送发布。

## 验收

- 主色在亮暗主题下都能区分活动态、可操作控件和非活动内容。
- P0–P4、逾期和完成状态继续可快速辨识。
- 所有实色按钮的文字可读，信息性文字达到至少 4.5:1 对比度。
- 已有交互、i18n、响应式布局与番茄钟功能保持不变。
