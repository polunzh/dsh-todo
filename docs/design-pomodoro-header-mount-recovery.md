# 顶栏番茄钟挂载恢复设计

## 证据

真实 DSH 会话页截图中，侧边栏的待办入口显示专注倒计时 `11:08`，说明番茄状态机和客户端插件都在运行。右上角只剩宿主自带控件，既没有计时器外框、进度环，也没有暂停或跳过按钮。

这组证据将问题定位到会话顶栏扩展的挂载路径。此前的读数样式修复仍保留为计时器已经挂载后的可见性保障。

## 视觉目标

沿用已确认的 [顶栏番茄钟目标图](./design-mockups/pomodoro-header.png)：在右上角宿主控件左侧保留一个紧凑的计时器组。

- 专注、短休与长休均显示 `mm:ss`；专注显示绿色进度环。
- 任务名打开待办面板；时间读数为信息展示；暂停/继续与跳过保持独立操作。
- 窄宽度优先保留时间与暂停/继续。

## 挂载设计

1. 以当前安装的 DSH 版本提供的真实会话页槽位为唯一注册目标；不以预览页的模拟槽位作为兼容性证据。
2. 让顶栏计时器在待办面板尚未打开时也能独立建立状态订阅、加载数据并持续刷新。
3. 对槽位注册增加可测试的契约：实际注册发生、组件可实例化、运行中的专注和休息均渲染出顶栏根节点。
4. 发布前在真实 GUI 中观察专注运行态，确认右上角同时出现计时器容器和秒级读数。

## 不变范围

不改变番茄状态机、侧边栏倒计时、既有主题切换中的未提交改动，以及已确认的顶栏交互层级。
