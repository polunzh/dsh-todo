# 番茄钟嘀嗒声：设计

## 背景

番茄钟已有两类声音：任务完成的双音、番茄结束的三音，都由插件设置里唯一的「提示音」开关管理。倒计时过程本身完全静音，用户只能看数字变化，缺少「时间在走」的持续感知。

用户希望专注计时时听到机械表式的嘀嗒（tick / tock），默认开启，并能配置关闭。

## 目标

- 专注计时运行中，每秒一声轻嘀嗒，tick 与 tock 交替。
- 默认开启；在插件设置里关闭，关闭立即生效（进行中的番茄也停）。
- 不改动番茄状态机、结束提示音、任务完成音、通知中心与侧边栏倒计时。

## 交互

### 声音

- 用 Web Audio 实时合成，沿用提示音的做法，不引入音频文件或新依赖。
- 每个嘀嗒是一段约 50ms 的噪声脉冲，经带通滤波后快速衰减：奇数秒 3.2kHz（嘀），偶数秒 2.4kHz（嗒）。
- 滤波后的输出峰值约 0.05–0.06（结束三音峰值 0.14），是短促的轻响；系统静音与系统音量始终优先。

### 时机

- 只在专注模式且运行中发声：开始后 1 秒第一声，之后每秒一声。
- 暂停、放弃、跳过立即静音；继续后从下一秒接着走。
- 短休、长休全程不嘀嗒。
- 到点时嘀嗒停止，由现有结束三音或通知中心接管，两者不叠在同一秒。
- 浏览器自动播放策略：开始 / 继续时在同一次用户手势里唤醒 `AudioContext`（复用现有 `primeAudio`），失败时静默降级。
- 后台标签页会被浏览器节流，嘀嗒可能变慢或停顿；这一版不做音频时钟预调度。

### 设置

- 插件设置 →「番茄设置」新增一行「嘀嗒声」，位于「提示音」正下方，默认开启。
- 行结构与提示音一致：左侧名称 + 10px 说明，右侧复选框 +「试听」。
- 「试听」播放三次 tick / tock，让用户不启动番茄也能判断音量与音色。
- 「提示音」保持只管任务完成与番茄结束，说明文案不变。
- 一个功能只有一个入口：入口仍是主面板右上角的「插件设置」，番茄钟视图不新增控件。

### 文案

| key | 中文 | English |
| --- | --- | --- |
| `settings.tickSound` | 嘀嗒声 | Ticking |
| `settings.tickSoundHint` | 专注计时每秒轻响，默认开启 | A soft tick every second while focusing; on by default |

「试听」复用 `settings.soundTest`（试听 / Test）。

## 布局

- 设置抽屉桌面宽 420px，新增行 `grid-column: 1 / -1`，与提示音行同宽；行右端的复选框 15px、试听按钮 26px 高，沿用现有尺寸。
- 窄屏（≤520px）抽屉铺满宽度，两行开关仍为单列，说明文字允许换行，试听按钮不换行。
- 深色宿主沿用 label / border token；嘀嗒声行在深色下与提示音行层级一致。

## 数据与接口

- 设置新增字段 `tickSound: boolean`，默认 `true`。
- `lib/store.js`：`DEFAULT_SETTINGS` 增加 `tickSound: true`；`SETTINGS_BOOLEANS` 加入 `tickSound`，让读取与 `updateSettings` 自动校验、持久化。
- 旧 `state.json` 没有该字段时由 `normalizeSettings` 补默认 `true`；显式保存过的 `false` 保留。
- `lib/index.js`：`todo` 工具 `settings` 动作接受 `tickSound`，schema 增加布尔字段。
- `lib/client.js`：`DEFAULT_SETTINGS`、`normalizedSettings` 同步；引擎每秒 tick 时读取实时设置。
- `docs/contract.md` 同步设置形状与行为说明。
- `preview/index.html` 的 mock 设置加 `tickSound: true`，预览与截图能看到开启状态。

## 非目标

- 不做音量滑杆、音色选择、随剩余时间加速或倒计时最后十秒变奏。
- 不为后台标签页做音频时钟预调度。
- 不把嘀嗒声接入通知中心（它只处理番茄结束）。
- 不新增设置入口或重复控件。

## 备选方案

**方案 A：合并进现有「提示音」。** 不加控件，只把说明改成「任务完成、番茄结束与专注计时共用，默认开启」。界面少一行，但无法只关嘀嗒、保留结束提示；对已经习惯提示音只响三次的用户，持续嘀嗒会变成不可分开的副作用。因此推荐方案 B。

## 验收

1. 专注计时运行中每秒一声 tick / tock；暂停、跳过、放弃、休息模式与到点后都静音。
2. 「嘀嗒声」默认开启，「试听」播放三次；关闭后立即影响进行中的番茄。
3. 「提示音」行为不变：任务完成双音、番茄结束三音或通知中心接管。
4. `tickSound` 可读写并持久化；旧数据迁移为 `true`；中英字典、工具 schema 与契约文档同步。
5. 完整测试、`node --check lib/client.js`、截图脚本通过；亮 / 深 / 中英 / 窄屏设置面板截图更新。
