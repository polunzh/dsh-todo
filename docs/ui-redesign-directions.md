# dsh-todo UI 升级 · 设计方向

> 目标：把整站 UI 提升到硅谷大厂商业产品水准，设计语言与细节全局统一（亮/暗、中英、响应式）。
> 本文用于确定方向。确认后写正式 design/plan 文档，再进入实施与逐轮截图优化。

## 一、现状诊断

当前实现结构完整、可用，但视觉上是「能用」而非「精致」：

- **信息密度失衡**：任务行左侧 2–4px 实色条过重，右侧 P 标签被推到最远端，中间留出大片空白，视觉重量分散。
- **顶栏拥挤**：P0–P4 五个筛选胶囊常驻，与搜索、刷新、番茄胶囊挤在一行，主次不清。
- **右侧大面积留白**：列表内容宽度铺满却信息稀疏，缺少「被设计过」的构图。
- **层级偏平**：标题/正文/次要信息字号差距小（13.5 / 11.5 / 11），节奏感弱。
- **番茄环偏旧**：粗红环 + 大数字，像早期计时器，缺少精致感。
- **日历格子空旷**，日格内信息弱。
- **圆角/阴影/间距**未成体系，各处取值零散。

## 二、三个方向（均已出高保真设计稿）

### A · Jade Precision（玉青 · 精准）— 推荐
冷中性底 + 玉绿强调，纤细分割线、紧致排版、克制深度。气质最接近 Linear / Vercel / Superhuman。
- 侧栏 236px，主区「内容列 + 右侧上下文栏（今日概览环 / 本周专注 / 接下来）」。
- 优先级用细指示条 + 右侧小号 P 标签，替代粗色条；筛选取代为一枚「优先级」下拉。
- 9 级字号体系，标题 20px / 正文 13.5px / 次要 11–12px。
- 已出**亮 + 暗**两版，验证暗色同样成立。

### B · Ink & Paper（纸墨 · 编辑）
暖纸底 + 近黑墨 + 苔绿点缀，衬线大标题，宽松留白，无硬质边框。气质接近 Things 3 / Craft / Bear。
- 内容居中单列（~720px），呼吸感强；任务行用细分隔线而非卡片。
- 更适合「从容、个人化」的日常场景，纵深与信息密度低于 A。

### C · Studio Vivid（鲜明 · 活力）
浅灰画布 + 白色浮起卡片，翡翠绿主色 + 珊瑚/琥珀/蓝的优先级色阶，头部进度环 + 番茄按钮。气质接近刷新后的 Todoist / Amie / Height。
- Hero 头部：大标题 + 环形进度 + 番茄入口；列表、快加均为独立卡片。
- 优先级用彩色胶囊，识别最高、最有「产品感」。

## 三、三个方向共用的底层系统（无论选哪个都统一）

- **间距**：4 / 8 基准网格（4·8·12·16·20·24·32）。
- **圆角**：控件 7–10 / 卡片 12–16 / 胶囊 999。
- **字号阶梯**：11 / 11.5 / 12 / 12.5 / 13.5 / 15 / 20 / 27（衬线大标题另设 44）。
- **色彩角色**：单一品牌绿（沿用 Logo #1fa774 系）+ 危险红 + 警告琥珀 + 信息蓝；优先级 5 级各有语义色，**只在这里用彩色**。
- **深度**：两级阴影，亮色极浅、暗色靠边框与更高对比。
- **状态**：hover / active / focus-visible 统一；焦点环统一 2px。
- **动效**：120–200ms、ease-out；勾选、抽屉、Toast、番茄切换统一节奏；尊重 `prefers-reduced-motion`。
- **强调色**：保留现有品牌绿，全站一致，暗色下提亮。
