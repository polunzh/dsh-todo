# Studio Vivid 配色方向设计

以现有 Studio Vivid 的信息结构为基准，只替换视觉色彩系统；任务优先级保持 P0 红、P1 橙、P2 黄、P3 蓝、P4 灰，避免主色破坏任务紧急程度的辨识。

## D1 · 深青专业

- 主色：`#087F82`；深色：`#05666A`；浅色：`#DFF3F2`
- 底色：`#EEF5F5`；内容表面：`#FBFDFD`
- 气质：可信、低刺激，适合高密度工作与长时间查看。
- 用法：导航选中、添加、已完成、专注进度均使用深青；专注主按钮保留深墨色以建立操作层级。

## D2 · 暖橙能量

- 主色：`#CB642E`；深色：`#A84E22`；浅色：`#FBE8DC`
- 底色：`#F6F1EA`；内容表面：`#FFFDF9`
- 气质：积极、有推动力，适合强调今日行动与专注启动。
- 用法：橙色覆盖主操作和进度，逾期与 P0 继续使用红色，避免紧急度与行动色混淆。

## D3 · 海军蓝稳重

- 主色：`#2867A9`；深色：`#1E528D`；浅色：`#E4EEF9`
- 底色：`#EFF3F8`；内容表面：`#FBFCFE`
- 气质：理性、专业，接近可靠的工作台工具。
- 用法：蓝色承担导航、完成和数据进度；冷色背景让时间、项目和统计信息更容易扫读。

## D4 · 玫瑰暖灰

- 主色：`#B84D68`；深色：`#943B53`；浅色：`#F8E5EB`
- 底色：`#F5F0F1`；内容表面：`#FFFAFB`
- 气质：温和、有辨识度，适合个人日程和习惯追踪。
- 用法：玫瑰色负责推进和完成，P0 保持更明亮的红，形成足够的任务风险差异。

所有方向都使用明度差和文字/图标共同表达状态，未依赖单独色相传达完成或优先级。
