# 任务行「开始专注」直接启动

## 背景

今天等任务列表右侧的播放按钮目前只会绑定所选任务，并跳转到番茄钟视图。详情抽屉的「开始专注此任务」已具备正确行为：绑定任务后立即进入专注计时，并留在当前界面。

## 目标

点击任务行右侧播放按钮后，立即以该任务开始专注计时；任务列表继续留在当前视图。

## 行为

- 空闲或暂停时：绑定该任务、切换至专注模式、立即开始倒计时。
- 已有计时运行时：更新绑定任务，不重置计时进度。
- 成功后显示现有的「已开始专注『{title}』」提示。
- 请求通知权限沿用现有用户手势内调用。
- 详情抽屉和任务行复用同一启动处理器，保证后续行为一致。

## 范围

- `lib/client.js`：任务行的 `ui.onFocus` 指向已有的直接启动处理器。
- `test/`：覆盖任务行入口使用直接启动路径，确保没有视图跳转。
- 不改动服务端存储、路由、工具、文案、视觉样式或计时状态机。
