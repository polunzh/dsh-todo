实物

真实任务行

标签右缘到图标按钮左缘固定 11px（行 gap）。hover 出图标时标签不位移；无优先级的行没有标签节点，标题直接占满整行。

另一处

标签和图标不在同一基线

标签中线跟标题行（18px）；30px 图标按钮从行内边距 9px 起排，中线落在 24px。两条线差 6px，右栏读起来是两层。拉平是独立决定：拉平后右栏只剩一条水平带，代价是按钮底色上沿从 9px 收到 3px。

规格

只改标签这一处

/* 新增三行，字号字重颜色不动 */
.todo-priority-label {
  min-width: 2ch;                     /* 两字符定宽槽 */
  text-align: right;                  /* 槽内贴右缘 */
  font-variant-numeric: tabular-nums; /* 数字等宽 */
}

/* P0 胶囊保留 padding，右缘与 P1–P4 同槽边 */
.todo-priority-label.todo-priority-p0 {
  padding: 0 6px; line-height: 16px;
}
  • 间距不变：标签右缘到首个图标 11px，来自行 gap；hover 出图标时标签不位移。
  • P0 胶囊按内边距向左外扩，右缘仍对齐，仍是“最紧急”的实心块。
  • 无优先级：标签节点不渲染，标题 flex:1 占满，图标列位置不动。
  • 暗色同一规则，标签色换 #f25a5a，等宽设置在两种主题下同样生效。
  • min-width 是给以后 “P10” 之类留的余量，当前 P0–P4 本来就占两字符。
