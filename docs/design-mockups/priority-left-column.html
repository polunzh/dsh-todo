行的两栏

  padding: 0 4px; border-radius: 5px;

/* 右栏：四个等宽按钮，间距 4px */
.todo-item-actions { display: flex; gap: 4px; }
.todo-icon-btn { width: 30px; height: 30px; }
理由

为什么这样就顺

  • 右栏只放同一种东西：四个 30px 图标键，同一尺寸、同一基线、同一悬停反馈，视觉上就是一条线。
  • 左栏本来就是竖列：复选框已经是一列，优先级补在同一列里，行首有了两个固定锚点，扫视时不再跳。
  • 优先级只表达一次：原来的 2px 色条与右侧 P1 是同一件事的两处显示，左移后去掉色条，颜色和字母合在一处。
  • 代价：标题和 chips 一起右移约 30px，无优先级的行留一列空白；换来的是行首两个固定锚点。
  • 排序和删除不受影响：仍留在右栏；要收成菜单是下一步的事，不卡在这次改动里。
