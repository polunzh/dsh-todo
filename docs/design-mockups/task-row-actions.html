右栏收成两个入口

现在 hover 时右栏一次出现五个目标：P1 加 上移 / 下移 / 专注 / 删除，按钮间距 2px，四个图标同粗细同灰度，扫一眼就是一片小字形。改法是把右栏压到「标签 + 一个主操作 + 一个菜单」，排序和删除收进菜单。

现状

五个目标挤在 150px 里

标签和四个按钮同处一条水平带，从 P 标签到最后一个按钮约 150px，按钮间距只有 2px。↑ 与 ↓ 形状几乎一样，删除键紧贴专注键右侧一格。

!右栏一次出现 5 个可点目标；↑ / ↓ 相邻读成一对重复符号；删除距专注只有 32px；四个图标同为 13px、1.7 描边、tertiary 灰，没有主次。
方案

三种右栏取舍

三种都保留 P 标签和 11px 槽间距，标签用等宽数字定宽。差别只在：右栏露出几个入口，排序和删除放在哪一层。

A

标签 + 开始专注 + 更多推荐
右栏两个按钮。上移 / 下移 / 删除收进「更多」菜单，详情抽屉不再放删除按钮。代价：排序要点两次。

B

只留开始专注
右栏一个目标，最干净。上移 / 下移搬进详情抽屉；删除只在详情里。代价：列表里完全不能调序。

C

保留三个，只做分层
删掉删除键，箭头降到 24px 弱化灰、间距 6px，专注用品牌绿。代价：右栏仍有三个图标，只是不再同级。

方案 A 细节

更多菜单与状态

「更多」是 30px 圆角按钮，菜单贴它右下展开、右缘对齐；打开时按钮转成按下态，行保持 hover 底色。菜单只三项：上移、下移、删除。删除离开播放键旁边，误点不再直接毁任务。

✓关闭：点菜单外部、按 Esc、再点「更多」都关。菜单打开期间行保持 hover 底色，指针移进菜单也不回白底。
✓边界：第一条的「上移」、最后一条的「下移」置灰；靠近视口底部时菜单向上弹。
✓删除单独成组：分隔线以下只有「删除任务」，与两项排序拉开，避免和上移挨着。
✓键盘：菜单打开后 ↑↓ 切换项、Enter 执行、Esc 关闭，焦点回到「更多」按钮。

附

选 A 的理由

  • 右栏只剩两个按钮：播放和更多，标签退回纯展示；鼠标扫过去是一条线，停顿时要判断的东西从 5 个降到 2 个。
  • 破坏性操作离开熟练动作：删除从播放键右侧 32px 移到菜单里，误点不再直接毁任务。
  • 排序慢一档可接受：调序是低频动作，菜单里点两次；以后真做拖拽排序，这层正好是过渡位。
  • 与标签修正叠加：标签槽定宽后，两行按钮组的左缘始终对齐，右栏不再随数字宽度抖动。
  • 实现约束：.todo-body 是滚动容器，菜单要用 fixed 定位挂到面板根节点、按按钮位置算坐标并做上下翻转，否则会被裁切。
  • 只动渲染层：onMove / onDelete 原样调用，数据结构不变；抽屉 footer 的删除按钮同时去掉，删除只留菜单这一处。
