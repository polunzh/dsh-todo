# 主题切换设计

## 目标

让用户在一个明确入口中切换五套已评审配色，并始终以「明亮工作室绿」作为新用户与未设置用户的默认主题。主题是插件的品牌配色，继续自动适配 DSH 的亮暗模式；它不替代宿主的浅色/深色开关。

## 入口与交互

在现有番茄钟右侧的「番茄设置」面板顶部新增一个独立的「外观」小节。该小节只有一行「主题」控件：按钮显示当前主题的小型三色样本、名称和下拉箭头。

点击按钮后在原位置弹出 320px 宽的主题选择器，包含五个等高选项：

- 明亮工作室绿（默认）
- 深青专业
- 暖橙能量
- 海军蓝稳重
- 玫瑰暖灰

每项由 24px 色彩预览、名称和一句气质说明组成。已选项同时用对勾、淡色底和文字标识，不依赖色彩单独传达选中状态。点击任一项立即应用、写入设置并关闭选择器；失败时回退至上一个主题并显示现有错误反馈。

## 视觉规则

- 默认主题为 `studio-vivid`，对应主色 `#10A37F`。
- 各主题继续保留 P0 红、P1 橙、P2 黄、P3 蓝、P4 灰，主色只服务导航、主操作、完成、进度和焦点。
- 每个主题提供亮暗两套令牌；用户切换 DSH 亮暗模式时，插件沿用所选主题的对应令牌。
- 主题选择器使用宿主表面、边框、阴影和焦点 token。实色选中底的文本使用显式对比色，信息文本至少达到 WCAG AA。
- 选择器在窄屏变为全宽弹层，锚定在主题按钮下方；移动端保留名称，不只显示色块。

## 无障碍与键盘

主题按钮具有 `aria-haspopup="listbox"`、当前主题名称和展开状态。弹层以 `role="listbox"` 呈现；每项为可聚焦选项并声明 `aria-selected`。支持上下方向键选择、Enter/Space 应用、Esc 关闭，关闭后焦点返回主题按钮。主题变更以简短状态文本确认一次，不做持续播报。

## 边界

此次只提供预设主题，不开放任意自定义颜色、主题导入/导出或独立主题管理页。所有主题在同一设置字段中持久化，并共享 DSH Web 与 Desktop 的本地状态文件。
