# 详情抽屉「开始专注」直接启动

## 背景

任务详情抽屉里的「开始专注此任务」按钮，当前调用 `ui.onFocus(task)`，其实现是 `pomodoroEngine.dispatch({type:"bind"})` 后 `setView("pomodoro")`——只绑定任务并跳到番茄钟页，并没有开始计时。

## 目标

在该按钮上点一下就能直接进入专注计时，不再跳转页面；抽屉保留在原处。

## 行为

- 点击时：`bind` 到该任务 → 若计时器空闲，切到 `focus` 模式并 `start`；已在运行则仅更新绑定。
- 弹出提示「已开始专注「{title}」」作为反馈。
- 保持单一入口：任务行右侧的专注图标仍走原来的「绑定并打开番茄钟页」行为，本次只改详情抽屉按钮。

## 范围

- `lib/client.js`：新增 `ui.onStartFocus`（绑定 + 直接开始，不 `setView`），详情抽屉按钮改用它；新增 i18n 键 `toast.focusStarted`（中英）。
- 不涉及存储、路由、工具。

## 验证

- 预览页无头验证：打开某任务详情 → 点「开始专注此任务」→ 计时器进入运行、视图仍停留在「今天」、抽屉仍在。
- `node --test` 全绿。
