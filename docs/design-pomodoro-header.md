# 番茄钟迁移到会话右上角：设计

## 背景

番茄钟目前挂载在对话输入框下方。该位置靠近页面底部，长对话和空白欢迎页都会让状态与开始/暂停操作远离视线。

DSH 运行时提供 `conversation.session.header.utilities`：会话页顶部右侧、现有最右角侧栏控制之前的工具区。它是可并列注册的列表插槽；`conversation.session.header.corner` 只允许一个控件，当前由宿主占用，因此不覆盖它。

## 目标

- 番茄钟在每个对话页的右上角保持可见、可操作。
- 用一枚紧凑的计时控件完成状态查看、开始/暂停、跳过和打开待办面板。
- 保持现有番茄状态机、任务绑定、通知权限请求与侧边栏倒计时行为。

## 交互

- 空闲的专注模式：显示进度环、`专注` 与预设时长；点击播放开始专注。
- 运行或暂停：显示模式、`mm:ss` 和进度环；主按钮切换暂停/继续；运行时保留跳过按钮。
- 绑定任务：只在有任务且宽度允许时显示一行截断标题；标题按钮始终打开待办面板。
- 短休、长休：沿用既有模式文案和强调色，避免将休息误读成专注。
- 工具提示和 `aria-label` 沿用现有本地化键；进度环继续只作为视觉补充，文本计时是可访问的状态来源。

## 布局与适配

- 注册到 `conversation.session.header.utilities`，排在常规会话工具之前，不接管最右角的宿主侧栏开关。
- 默认高度与宿主顶栏按钮一致；最小内容为进度环、时间和播放/暂停。空间收窄时先隐藏模式和任务名，始终保留时间与主操作。
- 移除 `conversation.composer.dock` 注册及输入框下方的计时条，确保一个功能只保留一个对话页入口。
- 侧边栏的秒级倒计时继续承担导航状态提示，不提供第二组开始/暂停按钮。

## 实现范围

- `lib/client.js`：将 `PomodoroHeaderTimer` 作为右上角计时工具，替换插槽注册与对应 CSS。
- `preview/index.html` / `scripts/screenshot.mjs`：用会话顶部工具区模拟新挂载位置，替换旧 dock 截图场景。
- `test/client-i18n.test.js` / `test/preview.test.js`：更新插槽、预览挂载与可访问性结构断言。
- `README.md` / `README.zh-CN.md`：替换入口说明与截图。

## 验收

1. DSH 会话右上角显示番茄钟，且宿主最右侧控制保持可用。
2. 开始、暂停/继续、跳过与打开待办面板都复用当前状态机并正常工作。
3. 窄宽时控件不与宿主工具重叠，任务名和模式可收缩，时间与操作按钮始终可用。
4. 中英文、亮暗主题、运行中和空闲状态均有预览截图；完整测试、语法检查和 UI 检测通过。
