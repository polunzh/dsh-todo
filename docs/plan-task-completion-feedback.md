## 验收标准

1. 勾选任务后，完成反馈在视觉上明显、任务标题可见，且不覆盖用户正在操作的输入控件。
2. 6 秒内可通过「撤销」恢复任务；重复任务同时显示下一次日期。
3. 完成成功时播放一次清晰、短促的确认音；唯一的「提示音」设置可关闭或试听，失败和撤销保持无声。
4. 其他通知维持原有层级；完成提示在亮暗、中文英文和窄屏下均清晰可用。
