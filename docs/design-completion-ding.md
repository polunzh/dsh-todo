# 完成提示音改为单声「叮」：设计

## 背景

任务完成播放上行双音，番茄结束播放三音上行。用户认为完成时不需要旋律，一声「叮」就够。

## 目标

- 任务完成与番茄结束都改成同一个单声「叮」。
- 提示音开关、试听按钮、通知中心接管逻辑保持不变。
- 嘀嗒声、分页提示、错误提示等其他声音不变。

## 声音

- 单个三角波振荡器，基频 1046.5Hz（C6），快速起音（6ms）后指数衰减约 0.65 秒。
- 番茄结束峰值 0.13，任务完成峰值 0.10；同一音色，后者略轻。
- 不引入音频文件或新依赖；系统静音与系统音量优先。

## 交互

- 番茄结束且没有通知中心接管时，播一次「叮」；装了通知中心时仍由它统一发声。
- 勾选任务成功且提示音开启时，播一次同一句「叮」；失败、撤销不发声。
- 插件设置里的「试听」播这声「叮」。

## 范围

- `lib/client.js`：用 `playDing` 替换 `playNotes` 的两段旋律；保留 `playChime` / `playCompletionChime` 两个入口，避免改动调用方。
- 测试：番茄结束的提示音断言从三音改为单声；完成路径的断言保持存在性检查。
- 文档与高保真稿：README、番茄钟设计文档、嘀嗒声设计稿里的「三音 / 双音」改为单声「叮」。
- 不改设置字段与界面结构，设置面板截图不变。

## 验收

1. 番茄结束只响一声「叮」，通知中心场景仍不重复发声。
2. 勾选任务只响一声同一音色的「叮」。
3. 「试听」与真实提示音一致。
4. 测试、语法检查与截图脚本通过。
